# Phase E — Qualified Teacher Review Checklist

This checklist is for a real reviewer. Automated Phase E tests must not set these gates to approved.

For every Class 3–5 competency, review the teaching blueprint and its source activities for:

- factual and mathematical correctness;
- one clearly defensible scored answer where automatic scoring is used;
- no hidden second valid answer among distractors;
- vocabulary, sentence length and conceptual load appropriate to the class;
- explanation teaches the reasoning rather than merely restating the answer;
- hint supports thinking without giving away independent/mastery evidence;
- independent and transfer tasks actually test the competency named in the curriculum contract;
- diagrams, map language, measurement units and scientific claims are precise enough to avoid misconceptions;
- cultural and household examples do not assume one family structure or one local practice;
- environment/recycling tasks distinguish classroom material-sorting examples from local municipal rules;
- reading questions distinguish literal recall, main idea, inference, comparison, vocabulary and evidence;
- grammar questions avoid sentences with multiple equally plausible target nouns/verbs/adjectives;
- productive writing/justification is judged from a learner-created response rather than multiple-choice recognition;
- narration says the same task the screen asks and does not reveal the answer;
- accessibility labels preserve the learning distinction rather than collapsing choices.

Record reviewer name, role, date, requested changes and approval only through the project’s formal review metadata workflow. Do not manually flip `paidEligibility` or external release-gate booleans merely because automated tests are green.
